# UI 与交互规范

## 设计基础

- 修改或新增 UI 前必须同时阅读本文件与 `style-standards.md`。Ant Design 是基础组件系统；已有 Lucide 图标可以继续使用，但同一操作域内不得混用不同线宽和尺寸，也不手写 SVG。
- 产品是内容编辑与发布工作台：界面保持安静、紧凑、便于连续写作和扫描，不使用营销式大字、渐变、玻璃模糊、大阴影或装饰卡片。

## 间距与层级

- 布局间距只使用 `4 / 8 / 12 / 16 / 24 / 32px`：4px 表示紧密关联，8px 表示同组元素，12px 表示关联内容，16px 表示同级模块，24px 表示主要区域，32px 仅用于大区块分隔。
- 表单标签到控件为 `8px`，控件到说明为 `8px`，同组字段为 `16px`；不得为单一页面临时增加 `10px / 14px / 18px / 20px / 22px / 28px` 等布局间距。
- 左侧发布平台栏固定 `200px`，右侧配置栏固定 `320px`；窗口不超过 `1180px` 时配置栏下移，不能继续压缩编辑与预览区。平台导航行高 `32px`，面板标题行最小高度 `44px`。
- 三栏桌面布局固定在一个视口内，右侧配置栏和编辑/预览面板各自滚动，禁止因配置内容增长把品牌与工作台头部卷出视口；配置栏下移后的窄窗口才允许页面级纵向滚动。
- 卡片只用于编辑器、预览、配置、动作和历史等真实工具边界，不增加卡片套卡片；层级主要通过边界、间距和背景表达，不使用大阴影。

## 字体与图标

- 全局字体固定使用 `-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`，Ant Design `fontFamily` 必须使用同一字体栈，禁止页面另设 `Public Sans`、`Inter` 或展示字体。
- 正文和控件文字为 `14px`，平台导航和紧凑说明为 `13px`，辅助信息为 `12px`，品牌副标题为 `11px`。工作台页面标题统一 `20px`，区块标题为 `14px` 或 `16px`。
- 普通按钮、平台导航、面板标题图标统一 `16px`；产品标识为 `28px`。文章预览可使用 `22 / 18 / 16px` 的 `h1 / h2 / h3` 阅读层级，但不得影响工作台导航和操作字号。
- 字号、图标和固定宽度必须在主题入口或相邻 CSS 集中定义，禁止用行内样式或临时组件参数单独放大。
- 普通 Ant Design 按钮沿用 Visual Worktree 基线：默认高度 `32px`、小按钮 `24px`、文字 `14px`，横向内边距使用同版本 Ant Design 默认 token。平台导航文字为 `13px`，但不得额外放大按钮内边距。
- 内容侧栏的品牌区只显示产品名和副标题，不显示应用 Logo 或功能图标；应用图标只用于冷启动、Dock、安装包和系统级品牌入口，避免与平台导航重复占位。

## 颜色与组件

### Visual Worktree 标准色板

所有桌面项目使用 Ant Design 默认 seed `colorPrimary: #1677ff`，再分别通过 `defaultAlgorithm` / `darkAlgorithm` 派生主题；禁止按主题手写另一套 `colorPrimary`。当前锁定的关键结果如下：

| 语义                 | 亮色      | 暗色      | 使用场景                       |
| -------------------- | --------- | --------- | ------------------------------ |
| `colorPrimary`       | `#1677ff` | `#1668dc` | 主按钮、当前导航、焦点、链接   |
| `colorPrimaryHover`  | `#4096ff` | `#3c89e8` | 仅用于 hover，不能作为暗色主色 |
| `colorPrimaryActive` | `#0958d9` | `#1554ad` | 按下态                         |
| `colorPrimaryBg`     | `#e6f4ff` | `#15325b` | 低强度选中背景                 |
| `colorSuccess`       | `#52c41a` | `#49aa19` | 成功、完成                     |
| `colorWarning`       | `#faad14` | `#d89614` | 警告、需注意                   |
| `colorError`         | `#ff4d4f` | `#dc4446` | 错误、阻断、危险操作           |
| `colorBgLayout`      | `#f5f5f5` | `#000000` | 页面底层                       |
| `colorBgContainer`   | `#ffffff` | `#141414` | 侧栏和主要容器                 |
| `colorBgElevated`    | `#ffffff` | `#1f1f1f` | 卡片、弹层、浮层               |
| `colorBorder`        | `#d9d9d9` | `#424242` | 控件和主要边界                 |

- 业务组件必须消费 Ant Design token 或与上表一一映射的语义 CSS 变量，不直接写主色、状态色和主题中性色。
- 启动页无法读取 React token 时，允许静态使用上表的 `colorPrimary`；亮色为 `#1677ff`，暗色为 `#1668dc`。
- `#4096ff` 只能表示亮色 hover；不得再作为暗色默认主色、常驻图标色或 loading 色。
- 图表、代码高亮和第三方平台品牌色属于独立数据语义，必须使用专用变量，并且不能覆盖应用交互主色。

- 深浅主题使用 Ant Design 蓝承载当前平台、主操作、链接和焦点；红色只表示错误或危险操作，绿/黄只表示成功/警告。正文、弱化文本、背景和边界只使用主题 token 或 `styles.css` 的语义变量。
- 布尔值用 Switch，选项集用 Select，纯图标按钮必须有 `aria-label` 或 Tooltip；加载、空、成功、失败和禁用状态都必须可读。

## 交互与状态

- 页面专用流程留在页面或对应 hook，只有真实复用时才创建共享组件。
- 异步动作覆盖初始、loading、空、成功和失败状态；执行中防止重复提交。
- 失败提示包含失败对象和可操作原因，不能只显示“操作失败”。
- 高频操作保持直接可达，危险操作使用确认弹层；键盘焦点和可访问名称完整。
- Electron 冷启动在 React 首次提交前使用静态主题背景、居中的 `112px` 项目图标和图标下方的 Ant Design 默认四点 `Spin` 形态；loading 容器为 `20px`、单点为 `9px`、与图标间距为 `16px`。开发态 macOS Dock 和跨平台窗口图标必须使用仓库内 `1024px` 透明项目 PNG，打包态继续使用平台安装图标；不得显示 Electron 默认图标。

## 截图验收

1. E2E 必须使用隐藏 Electron 窗口，截取默认平台、内容平台、深浅主题和最小窗口。
2. 逐张检查侧栏比例、编辑/预览宽度、字号、图标、间距、颜色语义、长标题和操作可达性。
3. 最小窗口和长内容下不得出现重叠、裁切、横向溢出或不可达操作；发布配置下移时仍需保持清晰分区。
